# Spec Kit, step by step

An interactive walkthrough of specification-driven development, using the history viewer as a worked example.

Download this repository and open `index.html` in a browser. No installation, build step or server is needed. Project details and progress stay in your browser; you can export them as a Markdown note.

The walkthrough includes the example's specifications, planning documents and commit history.

## Source

This repository is a standalone distribution snapshot of the canonical [history walkthrough](https://github.com/aanandi2021/history/tree/next/docs/speckit), exported from commit [`f843c09`](https://github.com/aanandi2021/history/commit/f843c09ba23512b98abaf3fc954041e0f2cd2696).

Make source changes in the history repository, then refresh this distribution. The `docs/speckit` and supporting `app` files retain their original layout.

The bundled Marked parser retains its upstream copyright notice and MIT license in `docs/speckit/vendor`.
